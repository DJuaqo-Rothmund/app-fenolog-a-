# 04 · Decisiones

| Tema | Decisión |
|---|---|
| Nombre | **FramBitácora** |
| Plataformas | **Solo Android** por ahora (Flutter permite sumar iPhone y web después) |
| Usuarios | **El dueño y su equipo** (una organización) |
| Volumen | **≈ 500 fotos por temporada**. Las fotos se guardan a 2048 px y calidad 85 (≈ 300-600 KB c/u) |
| Primer entrenamiento de IA | Hay fotos propias ya etiquetadas con su estadio |
| Sincronización | PowerSync sobre Supabase recomendado (etapa 4); motor propio como alternativa |
| Código | Abierto, licencia MIT (ver `LICENSE`) |
| Semana 1 | Por defecto, la semana que contiene el 7 de septiembre (frambueso); editable por temporada |
| Mapa | En el MVP solo GPS del teléfono; mapa sin conexión en una etapa posterior |
